# Créditos dos assets

As imagens deste diretório são composições. Os elementos visuais vêm de terceiros
e mantêm as licenças de origem — nada aqui é de autoria do projeto, exceto o
HTML/CSS que compõe as cenas.

`/usr/share/doc/kali-themes-common/copyright` e

independente, sem qualquer vínculo com a OffSec ou com o projeto Kali Linux; os
assets são usados para ilustrar como reproduzir a aparência da distribuição.

## O que é autoral

O HTML e o CSS em `html/`, a composição das cenas e os PNGs resultantes. Como o
material é liberado sob MIT, essa parte pode ser reusada livremente — mas os
assets de terceiros acima continuam sob as licenças deles, que são mais
restritivas que a MIT em pelo menos um ponto: GPL-3.0+ e CC-BY-SA-4.0 exigem
atribuição e propagação da licença ao redistribuir.
